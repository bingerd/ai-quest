# Steering status update

Write a one-page status update a busy, non-technical sponsor can read on a phone in two minutes.

## Steps

1. Find the engagement facts in the project knowledge: the statement of work, the latest facts, any earlier
   updates. Use only facts that appear there. If a fact you need is missing, say so in a short "Open
   questions" line rather than inventing it.
2. Decide the overall RAG status (Red, Amber or Green) and a one-sentence reason.
3. Write the update in this order:
   - **Status:** RAG and the one-sentence reason.
   - **Progress:** at most four bullets, measured against the statement of work.
   - **Risks:** at most three, each with an owner and a date.
   - **Decision needed:** the question, the options, and our recommendation in one line.
4. Check before you answer:
   - Every number appears in the source files.
   - No jargon: no "leverage", "synergy", "workstream alignment" and the like.
   - It fits on one page (about 250 words).
   - The decision is phrased as a question the committee can answer yes or no.

## Output

Return the update as plain text with the four headings above. Offer a .docx version only if asked.
