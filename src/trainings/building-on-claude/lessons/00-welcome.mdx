# Build AI features that survive production.

This training is for the engineers who put Claude in front of real traffic, and the platform teams who support them. In about half an hour:

- make prompt caching and batching do the heavy lifting on cost
- design a tool set an agent cannot misuse
- build an eval suite that catches regressions before customers do
- roll Claude Code out to hundreds of engineers without losing control
