# Cheat sheet

| Situation | Move |
| --- | --- |
| Same big prefix on every call | Stable content first, cache breakpoint after it, lifetime matched to call spacing |
| Nobody is waiting for the result | Batches API, 50% off |
| Not sure how big a request is | `count_tokens`, it is free |
| Bill tripled | Look at traffic first: repeated prefixes and unbatched async work before model choice |
| Agent needs to act | Read-only tools plus a draft; a human or an approved flow performs the irreversible step |
| Changing a prompt or model | Run the eval suite: happy, edge, adversarial, regression, graded by code where possible |
| Rolling out to an organisation | Managed settings for the floor, telemetry for visibility, a gateway if you need one |
| Agent in CI | `claude -p --bare`, explicit allowed tools, a turn limit, a scoped directory |
