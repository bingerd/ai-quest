# Make Claude Code yours, and your team's.

You already use Claude Code. This training is about the configuration that turns a good session into a great setup:

- a **CLAUDE.md** that carries the facts, not the fluff
- **settings.json** layers, and permission rules that actually hold
- **hooks** for things that must happen every time
- picking the right **extension point**: skills, subagents, MCP, output styles
- being your own **model router**, and keeping long sessions sharp

<ConceptCard title="Simulated, but real mechanics" icon="🧪">
  Nothing here runs Claude Code or a model. The permission matcher, hook events and settings layering follow the documented behaviour (checked September 2026), simplified to what you need to reason about. Costs and quality numbers are simulated.
</ConceptCard>
