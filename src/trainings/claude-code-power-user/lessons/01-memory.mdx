<ConceptCard title="Files are combined, not overridden" icon="➕">
  Every memory file that applies is loaded together. Put team facts in the project file and personal taste in your user file, and both are there.
</ConceptCard>

<ConceptCard title="Every line is paid for, every session" icon="💸" tone="warn">
  Memory loads into every session for everyone. Anthropic suggests keeping each CLAUDE.md under about 200 lines. Keep commands and conventions Claude cannot guess. Move long references into files and `@import` them. Drop generic advice like "write clean code".
</ConceptCard>

<ConceptReveal prompt="What should never be in CLAUDE.md?">
  Secrets. CLAUDE.md is usually committed and is always loaded into context. API keys belong in environment variables or a secrets manager. You can also run `/init` to generate a starter file and `/memory` to edit memory files.
</ConceptReveal>
