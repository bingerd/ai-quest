# Hooks: things that must happen every time

CLAUDE.md is a request. A **hook** is a command Claude Code runs at a specific moment, every time. Use hooks when "usually" is not good enough.

  title="Hook events you will use"

<ConceptCard title="Matchers and exit codes" icon="🎯">
  A matcher of `*` or empty matches everything. Plain names and `|` lists match exactly (`Edit|Write`). Anything else is treated as a regular expression (`mcp__.*`). Exit **0** is success. Exit **2** blocks where blocking is possible. Any other code is reported as an error but blocks nothing.
</ConceptCard>

<ConceptReveal prompt="Where do hooks live?">
  In the same settings files as everything else: `~/.claude/settings.json`, `.claude/settings.json` (shareable with the team), `.claude/settings.local.json`, managed settings, plugins, and skill or subagent frontmatter.
</ConceptReveal>
