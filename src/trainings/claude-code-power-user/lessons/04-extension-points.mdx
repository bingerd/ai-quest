# Skills, subagents, MCP and output styles

Beyond memory, settings and hooks, Claude Code has four more places to extend it:

<ConceptCard title="Suggestion, guarantee, or on demand?" icon="🧭">
  **CLAUDE.md** is always loaded and followed as guidance. **settings.json** is enforced. **Hooks** always run. **Skills** cost almost nothing until needed. **Subagents** keep noisy work out of your context. Choose by what you need: a fact, a rule, a guarantee, a workflow, or a clean context.
</ConceptCard>

Plugins bundle several of these (skills, agents, hooks, MCP servers, output styles) into one installable package.
