# Keeping long sessions sharp

The context window fills up as you work. Four commands keep you in control:

| Command | What it does | Use it when |
| --- | --- | --- |
| `/context` | Shows what is filling the window | Something feels heavy or slow |
| `/compact [focus]` | Summarises the conversation, keeping what you name | Same task, lots of noise, decisions to keep |
| `/clear` | Starts fresh | Switching to an unrelated task |
| a subagent | Does noisy work in its own context | Broad searches, reviews, investigations |
