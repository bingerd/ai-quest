# Cheat sheet

| I want… | Put it in |
| --- | --- |
| Facts and conventions for the team | `./CLAUDE.md` (short, with `@imports`) |
| My personal preferences | `~/.claude/CLAUDE.md` or `CLAUDE.local.md` |
| Enforced permissions for the team | `.claude/settings.json` |
| To try something just for me in this repo | `.claude/settings.local.json` |
| Something to happen every single time | A hook |
| A reusable workflow or `/command` | A skill |
| Noisy work out of my context | A subagent |
| Access to an external system | An MCP server |
| Deep thinking for design, speed for execution | `opusplan`, subagent `model:` |
| To see what fills my context | `/context` |
