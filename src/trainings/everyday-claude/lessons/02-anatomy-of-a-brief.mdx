# The anatomy of a good brief

A request to Claude is a brief, like one you would give a new colleague. The same six ingredients make the difference every time:

1. **Goal**: what the output has to achieve, not just the topic
2. **Audience**: who reads it, what they know, how much time they have
3. **Length and shape**: how many slides, how dense
4. **Sources**: the documents to use, and a request to cite them
5. **Storyline**: a simple structure to follow
6. **Format**: the file you actually need
