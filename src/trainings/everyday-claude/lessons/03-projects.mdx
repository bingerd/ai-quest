# Projects: set it up once

If you do the same kind of work more than once \u2014 and on an account you do it every week \u2014 a project saves you from repeating yourself.

- **Project knowledge** holds reference files: the firm's deck template, the signed statement of work, last quarter's steering report. Upload them once and every chat in the project can use them. Project content is reused rather than processed from scratch, so it is gentler on your usage limit than uploading the same file again and again.
- **Project instructions** hold the rules: tone, the client's house style, language, "one message per slide". Write them once instead of typing them into every chat.

<ConceptCard title="Rules are instructions, references are knowledge" icon="🗂️">
  If it tells Claude *how to work*, it is an instruction. If it is *material to work from*, it is knowledge. If you only need it once, it can stay in the chat. If it is personal or confidential and the task does not need it, it does not go in at all.
