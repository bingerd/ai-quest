# Cheat sheet

Before the final challenge, the habits in one place:

| Situation | Do this |
| --- | --- |
| Chat getting long and slow | Ask for a short summary, continue in a fresh chat |
| Same files every week | Put them in project knowledge |
| Same rules every time | Put them in project instructions |
| Need a deck | Give the goal, audience, length, sources, storyline and format, and ask for a .pptx |
| Something is wrong on one slide | Name the slide, the fix and the source, and say "change only that slide" |
| Close to your usage limit | Combine questions, keep files in a project, turn off tools you do not need |
| Personal or confidential data | Leave it out unless the task truly needs it and your company allows it |
| Before you send it | Check the numbers against the source yourself |
