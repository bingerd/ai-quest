<ConceptCard title="Three habits, three places" icon="🧭">
  Reference files you will use again go in a **project**, not an attachment. File creation is turned
  on under **Settings › Capabilities**. And when a routine job does not need it, turn the effort
  level **down** in the menu next to send.
</ConceptCard>
