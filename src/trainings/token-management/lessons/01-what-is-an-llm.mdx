# What is a large language model?

A large language model (LLM) is a system that takes in text and produces text, one small piece at a time. It has no memory between requests. Everything it "knows" about your situation has to be **in the request**.

<ConceptCard title="Stateless by default" icon="🔁">
  When you continue a chat, the whole conversation is sent again with your new message. The model does not remember; the application re-sends. That is why long chats get slower and more expensive.
</ConceptCard>
