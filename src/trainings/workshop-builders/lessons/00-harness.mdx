# The harness around the model

This morning you built Claude's environment by hand: instructions, files, design rules, a skill. A **harness** is that environment made systematic. It's the code that runs the loop around the model. Open each part.

<ConceptReveal prompt="Claude Code, Cowork and the Agent SDK: what do they have in common?">
  The same kind of harness. Cowork uses the agentic architecture that powers Claude Code, without a terminal. The Agent SDK gives you Claude Code's tools, agent loop and context management as a library in Python and TypeScript, so you can build your own agent on it.
</ConceptReveal>

<ConceptReveal prompt="When is an agent the wrong answer?">
  Often. Anthropic's own advice is to find the simplest solution that works and add complexity only when needed. A fixed workflow (step one, then two, then three) is cheaper and more predictable. An agent decides its own steps, which suits open-ended problems at the price of cost and errors that can compound.
</ConceptReveal>
